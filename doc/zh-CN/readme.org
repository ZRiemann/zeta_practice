* 项目定位

=zeta_practice= 是 ZetaX 下的综合能力练习应用，强调可重复练习、可测量反馈和持续能力提升。

它不是 LMS，也不是完整的在线教学系统。基础知识、键位常识、指法等内容可以由家长、
教师或其他材料完成教学；软件聚焦练习过程、结果统计、历史趋势和能力自适应。

首个落地模块为 =typing=。后续可以增加注意力、数学、语言、记忆等模块，但不能为了
未来可能存在的模块，在第一版中提前引入庞大的通用教育框架。

* 产品原则

- Web first：用户通过浏览器从不同设备访问。
- Cloud deployable：用户数据集中保存在服务端，不绑定某一台 Desktop。
- 多用户：通过密码登录，不同用户拥有独立的历史和能力状态。
- 中英文 UI：UI 语言和练习内容语言分离。
- 模块自治：每个练习模块拥有自己的领域规则、统计和自适应逻辑。
- 保持简单：优先单体服务和清晰模块，不引入微服务或预测性框架。
- 数据最小化：只保存认证、练习历史、统计和能力提升真正需要的数据。
