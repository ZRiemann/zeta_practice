#+TITLE: zeta_practice - Web-first Skill Practice Platform

[[file:./doc/en/readme.org][English Documentation]] | [[file:./doc/zh-CN/readme.org][中文文档]]

=zeta_practice= is a Web-first, multi-user practice platform in the ZetaX
workspace. It focuses on repeated practice, measurable feedback, and gradual
skill improvement rather than replacing basic human instruction.

The first planned practice module is =typing=.

* Current Status

Version =v0.2.0= delivers the Phase 1 Stage 1.1 application foundation: a
forge-managed Rust/Dioxus Web/Fullstack workspace, basic routes, and a bilingual
zh-CN/en-US application shell. Authentication, persistence, and typing behavior
remain planned for later Stages.

* Phase Roadmap

=Phase 1 - Typing= defines the first complete typing practice loop in 12 Stages.
Stage 1.1 is delivered in =v0.2.0= after validating the external =zeta_forge=
dependency prerequisite. Stages 1.2-1.12 remain planned; Phase 1 itself is not
yet complete.

* Product Direction

- Web first and cloud deployable.
- Multi-user with password authentication.
- Chinese and English UI.
- Independent and extensible practice modules.
- Server-side persistent data with SQLite as the initial database.
- Browser-local typing hot path; no per-keystroke network round trips.
- Simple, explainable adaptive practice rather than a large curriculum engine.

* Technology Direction

The intended implementation stack is Rust + Dioxus Web/Fullstack + SQLite.
The application should remain a small deployable monolith until measured scale
or operational requirements justify a more complex topology.

Rust public dependency versions and toolchains are governed centrally by
=zeta_forge=. This repository owns its application source, workspace structure,
feature choices, and =Cargo.lock=, but it must not establish a competing
third-party Rust dependency baseline.
